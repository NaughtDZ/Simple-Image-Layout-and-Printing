# 图片排版打印工具

一个用 **Python + PySide6 (Qt)** 编写的桌面小工具：把若干张大小不一的图片拖进窗口，
程序会将它们**等比例缩放、尽量铺满整个打印页面**，并提供**实时预览**与**打印**功能。

## 功能

- **拖放载入**：直接把图片文件（或整个文件夹）拖进窗口即可；支持常见格式
  （jpg / png / bmp / gif / webp / tif 等，取决于 Qt 的编译支持），自动处理 EXIF 旋转。
- **智能排版**：所有图片等比例缩放、无裁切、无拉伸；通过“贪心分行走宽 + 迭代目标行高”
  把图片尽量铺满整个页面。图片数量超出时自动分页。
- **页面设置**：纸张（A3 / A4 / A5 / B5 / Letter / Legal / 自定义）、纵向/横向、
  四周边距（mm）。
- **间距可调**：图片之间的间距、行与行之间的间距都可独立调节（mm）。
- **边框**：可选为每张图片添加简单边框，可调宽度（pt）与颜色。
- **顺序控制**：可在列表中拖拽调整顺序，也可按宽高比自动排序。
- **实时预览**：任何设置改动即时重排；支持滚轮缩放、拖拽平移、双击适应窗口。
- **打印**：内置系统打印对话框与打印预览（多页）。

## 安装

需要 Python 3.9+。安装依赖：

```bash
pip install -r requirements.txt
```

## 使用虚拟环境（推荐）

本项目使用项目内独立的 `venv` 虚拟环境，不污染系统 Python：

```bash
# 1. 创建虚拟环境（首次只需执行一次）
python -m venv venv

# 2. 安装依赖（首次只需执行一次）
./venv/Scripts/python.exe -m pip install -r requirements.txt
```

## 运行

**方式一（推荐，Windows）**：直接双击 `start.bat`，自动用项目内 `venv` 启动。

**方式二**：命令行运行：

```bash
./venv/Scripts/python.exe main.py
```

在 Git Bash 或 CMD 中也可先激活虚拟环境再运行：

```bash
# Git Bash
source venv/Scripts/activate
python main.py

# PowerShell
./venv/Scripts/Activate.ps1
python main.py
```

## 使用

1. 把图片拖进窗口（或在工具栏点“添加图片”），图片会出现在左侧列表。
2. 在左侧面板调整纸张、方向、边距、间距、边框、排列顺序——右侧预览实时更新。
3. 确认效果后，点击工具栏“打印预览”或“打印…”完成输出。

## 排版算法简述

- 每张图片只取其**宽高比**参与排版，尺寸统一按比例缩放。
- 把图片逐张累加到“当前行”，当加入下一张会导致行宽超过可用宽度时换行。
- 迭代一个“目标行高”，使最终排出的行数能把页面可用高度尽量占满；
  每一行的图片高度相同，整行宽度恰好等于页面可用宽度。
- 超过一页高度的行会自动滚动到下一页。

> 说明：启用边框后，图片会略微向内缩进以容纳边框线条，边框不影响整体排版间距。

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `main.py` | 程序入口 |
| `mainwindow.py` | 主窗口：拖放、设置面板、打印 |
| `layout_engine.py` | 排版算法（贪心分行走宽 + 迭代目标行高 + 分页） |
| `page_settings.py` | 页面设置数据与纸张尺寸表 |
| `renderer.py` | 预览 / 打印共用的页面绘制逻辑 |
| `preview_widget.py` | QGraphicsView 实时预览控件 |
| `image_store.py` | 图片信息读取与 LRU 解码缓存 |
